Global quadratic-funding coordination program that ReFi Barcelona describes as an active participant/track-record partner in its 2025 GG24 Catalunya proposal ("During 2025, ReFi Barcelona has actively participated in the global Regen Coordination program"). Same real-world org as "Regen Coordination" already present in the refi-dao-os reference store (data/kb/resource.yaml) — title kept identical intentionally so the two references dedup rather than fork. Per this document, Regen Coordination's GG23 global round funded 50 projects via 579 unique donors with $96,000 in matching funds, and "Regen Coordination Global" (cited separately in section 2.4 as a distinct localized-round example) pioneered AI-enhanced impact measurement using GPT-4o and Claude 3.7 models, establishing the Common Impact Data Standard (CIDS) — see companion claim-evidence object for the full figures and their uncertainty; these are self-reported program statistics quoted from a funding pitch, not independently verified here.
