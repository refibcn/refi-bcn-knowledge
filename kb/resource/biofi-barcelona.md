First community event on bioregionalism and regenerative finance in Catalunya, held Monday–Tuesday May 26–27 (year not stated in source; a sibling case-study file in the same directory frames it as an introductory/first edition — treat as unconfirmed). Hosted at Bloc4; co-organized by Commons Agency and ReFi Barcelona; sponsored by Celo Europe, EthicHub, and ReFi Mediterranean. 30+ participants across ReFi Barcelona/ReFi DAO/Regen Coordination, permaculture designers, Web3 and cooperative-movement technologists, academics, community organizers, and consultants. Day 1 ("¿Qué es BioFi?") covered BioFi/BFF fundamentals (Design School for Regenerating Earth framework, Resilience.Earth's Catalunya organizing experience); Day 2 ("¡Organicemos nuestra biorregión!") covered ReFi Barcelona/Mediterranean coordination, the Bioregional Knowledge Commons framework, and a participatory workshop ("Laboratorio de Imaginación Biorregional"). Named outcomes: the Catalunya Bioregional Knowledge Commons framework, a collaborative Miro board, a "Community Contacts Spreadsheet" (living directory of 30+ participants' skills/needs/affiliations — access is request-only via Telegram, not public; flagged via public-use-boundary, no person-nodes derived), and the Gardens Pool Initiative. `high_risk: true` set because this object references the existence of that participant-directory artifact — see accompanying public-use-boundary candidate.
